# STM32 FreeRTOS Starter Project

This project is a minimal STM32 + FreeRTOS starter layout.

## Structure

- Core/Inc - application headers
- Core/Src - application source files
- Drivers - place STM32 HAL/CMSIS drivers here
- Middlewares/Third_Party/FreeRTOS - place the FreeRTOS source tree here

## Notes

This generated project is a source/layout starter. MCU-specific startup code, linker scripts,
HAL initialization, clock configuration, and FreeRTOS port files depend on the exact STM32 MCU.
